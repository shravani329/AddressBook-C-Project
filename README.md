# Address Book Management System in C

## Project Overview

A menu-driven Address Book application developed using C. It allows users to create, search, edit, delete, and display contacts.

## Features

- Create, search, edit, and delete contacts
- Display all contacts
- Save and load contacts using file handling

## Technologies Used

- C programming
- Structures and pointers
- Functions and modular programming
- File handling

## How to Compile and Run

Compile:

    gcc main.c contact.c file.c -o addressbook

Run:

    ./addressbook

## Learning Outcome

Practised C programming concepts by developing a menu-driven application with file handling.
